PRIMEIRA VEZ AQUI?

Prepare seu acesso em 3 passos

Você vai criar um acesso neste Router. Ele é separado da sua conta da Biziva e da sua conta do ChatGPT ou Claude.

  1. Encontre o código de instalação.

    Abra a pasta onde você instalou o Biziva Router. Abra o arquivo .env com um editor de texto e encontre a linha que começa com ROUTER_ADMIN_TOKEN=. Copie somente o código depois do sinal =, sem alterar o arquivo.

    Não estou vendo o arquivo .env

    O arquivo é criado ao executar npm run setup na pasta do Router. Ele pode ficar oculto: no Mac, pressione Command + Shift + ponto; no Windows, ative a opção de mostrar arquivos ocultos no Explorador. Se outra pessoa instalou o Router para você, peça a ela para criar seu acesso e entregar seu código pessoal.

    Não apague nem recrie o arquivo para resolver um problema de acesso. Ele também guarda informações necessárias para abrir os dados já salvos.

  2. Crie seu acesso.

    Cole o código de instalação abaixo e escolha um nome curto, como meu-acesso. Esse nome serve apenas para identificar seu acesso; não precisa ser seu nome completo ou e-mail.

    Use letras sem acento, números, hífen ou sublinhado. Não use espaços.

  3. Guarde seu código pessoal e adicione sua chave de IA.

    Seu código pessoal aparecerá abaixo após a criação. Guarde-o como uma senha. Você já ficará conectado e poderá cadastrar sua chave de IA no próximo quadro.

O código de instalação permite criar acessos. O código pessoal permite usar sua conta. A chave de IA vem do provedor escolhido. Guarde os três em local seguro e não os envie em mensagens ou capturas de tela.
